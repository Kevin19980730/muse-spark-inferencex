# Muse Spark Open on InferenceX - daily trend (published copy)

Static web copy of `inferencex-muse/muse_spark_trend.html`: SemiAnalysis InferenceX agentic-trace runs of
Muse Spark Open 816B, per chip, as daily as-of time series of token throughput per all-in utility MW, throughput
per chip, cost per million tokens, tokens per $1 TCO and token revenue per GPU hour at a fixed P90 interactivity.
`muse_trend.csv` holds the trend rows, `muse_points.csv` every measured point by as-of date.
Generated by `inferencex-muse/publish_site.py` on the source PC - do not edit here; every publish overwrites the files.
